# 咔位 · 安卓试用原型

> 首发渠道为 Google Play，使用个人开发者账号。商店公开名称和联系 Gmail 在准备提审时确认。

0.16.0：面向 Android 16（API 36）构建，并支持使用 Google Play 上传密钥生成签名 AAB。自选参考图拍摄后的分享卡按自选参考显示。

0.15.0：相机取景页可直接调整参考浓度、一键显隐、点击缩略图查看原图。支持点按对焦、连续变焦和快捷倍率。闪光灯开关控制快门闪光，常亮补光可在“更多”中设置。

0.14.0：自选参考照片使用拍照测试版验证过的本地线稿模型和构图主线预设。内置模板和自选照片均可通过相机右上角选择线稿、半透明原图或关闭参考，分别记住原图、线稿的浓度。照片读取完成即可用原图取景，线稿在后台继续生成。参考叠加只显示在取景画面中。

0.13.0：提高自选照片线稿的本地生成质量。人物区域使用更高推理分辨率并保留脸、头发、手部和衣物细节；背景在进入模型前先去除高频纹理，输出后按局部线条密度过滤树叶、砖纹和小字等碎线，背景浓度保持 35%。人物分割使用独立图像副本，兼容会在任务结束时回收输入 Bitmap 的 ARM 厂商实现。

0.12.0：手机本地生成线稿时显示分阶段百分比进度。生成期间可以返回并继续浏览或拍照，任务会在应用内后台继续；首页状态条持续显示进度，完成或失败后可点击查看或重试。

0.11.1：修复自选参考图在相机中静默显示半透明原图的问题。旧版本保存的照片在缺少线稿时会自动补生成；相机顶部明确标记“线稿模式”或“原图模式”，并提供一键切换。线稿缺失或损坏时不再假装使用线稿，而是返回生成页面提示处理。

0.11.0：在首页和场景页的“更多”菜单中加入语言设置，可选择跟随系统、简体中文或 English。切换后立即刷新，重启应用后保持选择；中文模式使用素材库已有的中文场景、机位、动作和光线说明。

0.10.0：自选照片可在 Android 设备本地生成细线参考图。人物线保持清晰，背景线使用 35% 浓度；生成后可对照原图、重新生成、使用原图或直接进入相机。模型随安装包提供，处理过程不上传照片。若设备无法加载人物分割模块，仍会生成整幅 35% 浓度的细线参考图。

0.9.1：当前验证阶段取消分享解锁门槛，所有内置模板全部开放。新手引导继续保留；分享卡只作为自愿传播入口，不限制模板、拍摄或保存。

0.9.0：原生界面以 `ui-prototype` 为视觉与信息架构基准重做。首页改为品牌头部、场景搜索、继续拍摄、场景卡片、快捷拍法和每周热门；场景页加入大图封面与双列内容；拍法详情改为暗色成片加底部操作面板；相机将倒计时、曝光、网格、辅助浓度、补光与拍摄建议收进“更多”，首屏只保留参考、倍率、圆形快门和切换镜头。

0.8.1：把新手指导和裂变能力做成正式可见界面，而不是系统弹窗和普通按钮。新增独立新手欢迎页、首页“新手第一拍”任务卡、锁定模板遮罩、相机画面内嵌跟拍提示，以及结果页分享奖励模块。

0.8.0：加入新用户首次跟拍引导和首次相机三步提示。每个场景前 5 个模板可直接使用；其余模板显示“分享解锁”。用户完成拍摄后可生成不修改原图、不拉伸照片的同款拍法卡，选择分享目标后解锁当前场景全部拍法。Android 只能确认用户选择了分享目标，不能证明内容最终发布，因此当前版本不把它描述为“发布验证”。

0.7.0：相机页加入前后镜头切换。前置自拍默认按镜像方向保存，使相册结果与取景预览一致；可在相机工具栏关闭“镜像”。切换镜头时会重新读取该镜头支持的变焦、曝光和补光能力，没有前置或后置镜头时自动保留可用镜头。

0.5.0：采用“小红书灵感画册”界面。首页分为“精选拍法 16”和“热门灵感 60”；热门灵感完整收录街边、咖啡店、公园、海边、草原、山野六组原始素材，并按现有四个产品场景筛选。灵感可查看大图并直接作为半透明拍摄参考。

0.4.1：接入 16 张内部试用参考图，街边、咖啡店、公园、旅行各 4 张；拼图已拆分为独立构图并等比例增强清晰度。除长椅模板外，其余新图暂用半透明原图辅助，尚未制作独立线稿。第三方平台素材公开发布前需确认授权或替换。

0.4.0：数据驱动的四个场景入口、双列等比例照片卡片、姿势/横竖筛选、独立拍法预览、最近使用、结果默认大幅实拍。缺少素材的场景展示空状态。扩展方法与收集清单见 [CONTENT-GUIDE.md](CONTENT-GUIDE.md)。

0.3.1：变焦和曝光改为直接滑杆、调节时暂时隐藏参考叠图，光线建议与实际补光灯分开，倒计时居中显示。设备端画面不变的问题尚未由真机证实修复。

0.3.0：四张成片（长椅侧坐、林间侧身、林间回头、暖光侧脸）和对应透明线稿；九宫格、线稿浓度、黑白切换、按住看原图；双指变焦、倍率快捷按钮、曝光补偿、点按对焦反馈、0/3/10秒延时；拍后并排或单图对比；每个模板独立光线提示。内置参考素材来自用户，仅用于内部试拍。

旋转手机后控制区移到侧边；模板决定取景比例，竖图保持竖幅，横向自选参考图可拍横幅，不强行拉宽或裁切模板。自选照片默认在本地生成细线参考图，也可切回半透明原图。倍率并非光学焦段承诺，具体范围由CameraX设备能力决定。

Android 10及以上。先用小米15 Pro测试；华为Pura 70 Pro需要确认HarmonyOS版本，不能承诺安卓安装包适用于原生鸿蒙。

## 真机验收

1. 首次允许相机权限；拒绝后重新进入或到系统设置授权。
2. 选择长椅侧坐；检查原图、线稿、预览和保存照片的画幅及方向一致；短屏应留边，不能拉伸。
3. 导入横向、纵向参考照片，查看方向和清晰度。
4. 开关辅助并拍照，确认辅助线不进入照片。
5. 保存后在相册Pictures/ShotGuide确认原图；重复点击不会重复保存。
6. 切到后台再回来、连续拍摄、拒绝权限后恢复，检查相机是否可继续使用。
7. 首页可查看和复制本机操作记录。满意标记是操作次数，不是去重成功率。
8. 四张模板分别进入相机；双指缩放、点按对焦、设置曝光后拍照，对比结果并继续拍，确认倍率/曝光保留。
9. 拍摄中和结果页旋转手机，检查快门可见、图片无拉伸、成片方向正确。试用横向参考照片拍摄。
10. 测试3秒/10秒倒计时，切后台或旋转会取消尚未触发的倒计时。
11. 光线提示是模板建议，未做现场AI识别；生成式线稿为姿态参考，不保证逐像素配准。
12. 切换到前置相机，确认预览正常、线稿可对齐、默认保存结果与预览左右方向一致；关闭“镜像”后确认保存为非镜像方向。反复切换前后镜头并分别测试拍照、倒计时、曝光和返回。
13. 清除应用数据后首次打开，确认出现“先完成第一张跟拍”；进入相机时确认只出现一次“三步完成跟拍”。
14. 所有场景的全部模板均可直接打开，不显示“分享解锁”遮罩，也不要求先完成分享。
15. 拍完后点击“分享同款”，确认卡片只使用实拍结果、不修改相册原图、画面比例正确且没有拉伸；取消或完成分享都不改变模板权限。
16. 导入自选照片，在线稿生成期间进入原图模式；生成完成后从相机右上角切换到线稿，确认取景范围与原图一致。分别调节两种模式的浓度，再切换确认上次的浓度得到保留。
17. 从“更多 → 语言”分别切换跟随系统、简体中文和 English；检查首页、场景、模板详情、自选线稿、相机和结果页，并重启应用确认语言选择保持。

目前没有账号、联网、广告或付费。照片和自选线稿不会上传；自选参考图与最近生成的线稿保存在应用私有目录，选择另一张照片时替换。未保存的实拍照片暂存在应用缓存，重要照片请点击保存。

## 电脑交互预览

双击根目录的 `preview-android.cmd`，打开 `ShotGuide_UI` Android 模拟器并安装当前构建的 APK。也可运行 `./preview-android.ps1 -Build`，先编译再打开。模拟器使用独立端口 5580，不会将安装包发送到连接的手机。

鼠标点击模拟触摸，按住拖动浏览照片；模拟器右侧旋转按钮切换横竖屏。可检查场景、筛选、空状态、照片预览和返回流程。首次启动较慢，以后可以离线启动。

该预览运行真实 Android App，不是网页仿制。相机设备在该启动配置中关闭，拍照及真实曝光、变焦仍需手机测试。

## 构建命令

JDK 17、Gradle 8.11.1、Android SDK 36、Build Tools 36.0.0。`local.properties`为本机 SDK 路径。

- `.\build-local.ps1` 生成用于手机安装测试的 Debug APK。
- `.\build-local.ps1 -PlayBundle` 生成用于本地检查的未签名 Release AAB。
- `.\build-local.ps1 -PlayBundle -SigningProperties <本机文件路径>` 使用已有上传密钥签名 AAB。

签名配置示例见 `play-signing.properties.example`。将其复制到项目目录之外并填入本机上传密钥信息，再传给 `-SigningProperties`；配置文件和密钥由开发者保管，不要提交到版本库。Windows 路径可使用正斜杠。

真机体验尚需实际连接设备验证，编译通过不代表拍照兼容性已经通过。
